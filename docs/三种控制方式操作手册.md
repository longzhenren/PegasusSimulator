## 系统概览

### 对比表

| 特性 | MAVROS | 纯MAVLink | 纯Python |
|------|--------|-----------|----------|
| **依赖** | PX4, MAVROS, ROS2 | PX4, pymavlink | 无 |
| **启动时间** | ~30s | ~15s | ~5s |
| **资源占用** | 高 | 中 | 低 |
| **PX4飞控** | 真实 | 真实 | 模拟 |
| **控制精度** | 高 | 高+ ⭐ | 中 |
| **ULG日志** | 有 | 有 | 无 |
| **仿真端口** | 8081 | 8081 | 8081 |
| **控制端口** | 5009+id | 5009+id | 5009+id |
| **PVA前馈控制** | P+V | P+V+A ⭐ | P |
| **高动态参数** | 手动配置 | 自动配置 ⭐ | N/A |

**⭐ 纯MAVLink新增特性：**
- **PVA控制**：位置+速度+加速度三级前馈，最小化跟踪误差
- **高动态参数自动配置**：建立连接时自动设置MPC参数（倾角、增益、jerk限制等）
- **TrajectorySmoother**：三次样条插值，50Hz平滑轨迹跟踪

## 系统一：MAVROS控制

### 启动方法

#### 终端1：启动Isaac Sim + PX4 SITL + MAVROS
```bash
# 8机配置
ISAACSIM_PYTHON examples/8_camera_vehicle.py \
  --config examples/multi_uav_config_8.json

# 单机配置
ISAACSIM_PYTHON examples/8_camera_vehicle.py \
  --config examples/multi_uav_config_1.json
```

#### 终端2：启动数据采集
```bash
# 基础采集
python examples/trajectory_data_collector.py \
  --input-dir ~/trajectories \
  --out-dir ~/recordings \
  --config examples/multi_uav_config_8.json

# 速度前馈OFFBOARD模式（新增）
python examples/trajectory_data_collector.py \
  --input-dir ~/trajectories \
  --out-dir ~/recordings \
  --velocity-offboard

# Mission模式
python examples/trajectory_data_collector.py \
  --input-dir ~/trajectories \
  --out-dir ~/recordings \
  --mission-mode
```

### 数据保存位置

### 主要参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--input-dir` | (必需) | 轨迹JSON文件目录 |
| `--out-dir` | `./recordings` | 输出目录 |
| `--config` | `multi_uav_config.json` | UAV配置文件 |
| `--uav-ids` | 从配置读取 | 指定UAV ID，逗号分隔 |
| `--control-base` | `http://127.0.0.1:5009` | 控制器基础URL |
| `--image-base` | `http://127.0.0.1:8081` | 图像服务URL |
| `--scale` | `0.01` | 坐标缩放因子（cm→m） |
| `--z-down` | 默认 | Z轴向下（ENU→NED） |
| `--z-up` | - | Z轴向上（保持ENU） |
| `--reset-timeout` | `240s` | 重置超时时间 |
| `--cmd-timeout` | `120s` | 命令超时时间 |
| `--image-timeout` | `10s` | 图像获取超时 |
| `--image-retries` | `30` | 图像重试次数 |
| `--skip-existing` | 默认启用 | 跳过已存在轨迹 |
| `--no-skip-existing` | - | 不跳过已存在轨迹 |
| `--mission-mode` | - | 使用MAVROS Mission模式 |
| `--velocity-offboard` | - | 使用速度前馈OFFBOARD模式（50Hz控制） |
| `--dry-run` | - | 仅扫描文件，不执行 |

### ⭐ 高动态参数配置（新增）

MAVLink控制器在建立连接时会自动配置PX4的高动态飞行参数，优化轨迹跟踪性能：

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| `MPC_TILTMAX_AIR` | 60.0° | 空中最大倾角（默认35°→60°） |
| `MPC_MAN_TILT_MAX` | 60.0° | 手动模式最大倾角 |
| `MPC_XY_P` | 1.5 | 水平位置P增益 |
| `MPC_XY_VEL_P_ACC` | 3.0 | 速度到加速度增益 |
| `MPC_Z_P` | 1.5 | 垂直位置P增益 |
| `MPC_Z_VEL_P_ACC` | 6.0 | Z轴速度到加速度增益 |
| `MPC_THR_HOVER` | 0.55 | 悬停油门（补偿大倾角） |
| `MPC_JERK_AUTO` | 20.0 | 自动模式最大jerk (m/s³) |
| `MPC_XY_VEL_MAX` | 12.0 | 最大水平速度 (m/s) |
| `MPC_Z_VEL_MAX_UP` | 4.0 | 最大上升速度 (m/s) |
| `MPC_Z_VEL_MAX_DN` | 3.0 | 最大下降速度 (m/s) |

**效果：**
- 允许更大的水平加速度（大倾角）
- 提高XY轴跟踪刚度，更快响应位置误差
- 强化Z轴稳定性，防止大倾角时高度掉落
- 减少平滑限制，允许瞬间大加速度

### ⭐ TrajectorySmoother（三次样条插值）

采集器使用三次样条插值对轨迹进行平滑处理：

```python
# mavlink_trajectory_collector.py 中的 TrajectorySmoother 类
smoother = TrajectorySmoother(points, dt=0.2)  # 5Hz输入数据
state = smoother.get_full_state(t)
# 返回: x,y,z, vx,vy,vz, ax,ay,az, roll,pitch,yaw, yaw_rate
```

**特性：**
- 对位置(x,y,z)和姿态(roll,pitch,yaw)进行三次样条插值
- 自动处理角度的unwrap（防止±180°跳变）
- 计算一阶导数（速度）和二阶导数（加速度）
- 50Hz控制循环发送PVA setpoint

## HTTP API 完整参考

所有三种控制方式使用**完全兼容的HTTP API**，便于切换和测试。

### 端口分配

| 服务 | 端口 | 说明 |
|------|------|------|
| 仿真服务 | `8081` | 图像、位姿、PX4状态 |
| 控制器0 | `5009` | UAV 0 控制 |
| 控制器1 | `5010` | UAV 1 控制 |
| 控制器N | `5009+N` | UAV N 控制 |

---

### 仿真服务 API (端口 8081)

#### 1. 获取位姿
```bash
GET /uav/<id>/pose
```
**响应：**
```json
{
  "uav_id": 0,
  "timestamp": 1704067200.123,
  "position": [1.0, 2.0, 5.0],
  "attitude": [0.0, 0.0, 0.0, 1.0],
  "linear_velocity": [0.1, 0.2, 0.0],
  "angular_velocity": [0.0, 0.0, 0.01],
  "linear_acceleration": [0.0, 0.0, 0.0]
}
```
**示例：**
```bash
curl -s http://127.0.0.1:8081/uav/0/pose | jq .
```

---

#### 2. 获取图像（JSON + Base64）
```bash
GET /uav/<id>/image
```
**响应：**
```json
{
  "uav_id": 0,
  "timestamp": 1704067200.123,
  "width": 640,
  "height": 480,
  "channels": 4,
  "encoding": "png_base64",
  "mime": "image/png",
  "data": "iVBORw0KGgoAAAANSUhEUg...",
  "data_url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUg..."
}
```
**示例：**
```bash
# 获取图像元数据（不含数据）
curl -s http://127.0.0.1:8081/uav/0/image | jq 'del(.data, .data_url)'

# 保存图像
curl -s http://127.0.0.1:8081/uav/0/image | jq -r '.data' | base64 -d > image.png
```

---

#### 3. 获取图像（二进制PNG）
```bash
GET /uav/<id>/image.png
```
**响应：** 二进制PNG图像数据

**示例：**
```bash
curl -s http://127.0.0.1:8081/uav/0/image.png -o image.png
```

```bash
GET /uav/<id>/all
```
**响应：**

```json
  "uav_id": 0,
```

```bash
  curl -s http://127.0.0.1:8081/uav/$i/all | jq -c '.pose.position'

```

#### 5. 重置UAV位置
```bash
POST /uav/<id>/reset
```
**请求体：**

##### 3.4 PVA前馈设定点 (setpoint) ⭐更新
**请求体：**
```json
{
  "cmd": "setpoint",
  "x": 1.0,
  "y": 2.0,
  "z": 5.0,
  "vx": 0.5,
  "vy": 0.0,
  "vz": 0.0,
  "afx": 0.1,
  "afy": 0.0,
  "afz": 0.0,
  "yaw": 0.0,
  "yaw_rate": 0.0
}
```
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `x` | float | 0.0 | 目标X位置 (ENU, 米) |
| `y` | float | 0.0 | 目标Y位置 (ENU, 米) |
| `z` | float | 0.0 | 目标Z位置 (ENU, 米，向上为正) |
| `vx` | float | 0.0 | X方向速度前馈 (m/s) |
| `vy` | float | 0.0 | Y方向速度前馈 (m/s) |
| `vz` | float | 0.0 | Z方向速度前馈 (m/s) |
| `afx` | float | 0.0 | X方向加速度前馈 (m/s²) ⭐新增 |
| `afy` | float | 0.0 | Y方向加速度前馈 (m/s²) ⭐新增 |
| `afz` | float | 0.0 | Z方向加速度前馈 (m/s²) ⭐新增 |
| `yaw` | float | 0.0 | 目标航向角 (弧度) |
| `yaw_rate` | float | 0.0 | 航向角速度 (rad/s) |

**PVA控制说明：**
- **P** (Position): 位置目标
- **V** (Velocity): 速度前馈，提高轨迹跟踪响应速度
- **A** (Acceleration): 加速度前馈，进一步减少跟踪误差

**坐标系说明：**
- 输入坐标系：**ENU** (East-North-Up)
- 控制器内部转换为 **NED** (North-East-Down) 发送给PX4
- MAVLink type_mask = 0x0000（使用全部PVA字段）

**示例：**
```bash
# 发送PVA setpoint（位置+速度+加速度）
curl -s -X POST http://127.0.0.1:5009/command \
  -H "Content-Type: application/json" \
  -d '{
    "cmd": "setpoint",
    "x": 1.0, "y": 2.0, "z": 5.0,
    "vx": 0.5, "vy": 0.0, "vz": 0.0,
    "afx": 0.1, "afy": 0.0, "afz": 0.0,
    "yaw": 0.0, "yaw_rate": 0.0
  }' | jq .

# 50Hz PVA轨迹跟踪（Python示例，使用三次样条插值）
import requests, time
from scipy.interpolate import CubicSpline
import numpy as np

# 假设已有轨迹点和样条插值器
for t in np.arange(0, 10, 0.02):  # 10秒，50Hz
    x = float(spline_x(t))
    vx = float(spline_x(t, 1))  # 一阶导数
    ax = float(spline_x(t, 2))  # 二阶导数
    requests.post("http://127.0.0.1:5009/command", json={
        "cmd": "setpoint",
        "x": x, "y": 0, "z": 5,
        "vx": vx, "vy": 0, "vz": 0,
        "afx": ax, "afy": 0, "afz": 0,
        "yaw": 0, "yaw_rate": 0
    })
    time.sleep(0.02)
```

### 常用HTTP脚本

#### 完整采集流程脚本
```bash
#!/bin/bash
# 单机采集流程示例

UAV_ID=0
CTRL_PORT=$((5009 + UAV_ID))
SIM_URL="http://127.0.0.1:8081"
CTRL_URL="http://127.0.0.1:$CTRL_PORT"

# 1. 检查健康状态
echo "=== 检查系统状态 ==="
curl -s $CTRL_URL/health | jq .
curl -s $SIM_URL/uav/$UAV_ID/px4/ready | jq .

# 2. 重置到初始位置
echo "=== 重置位置 ==="
curl -s -X POST $CTRL_URL/reset \
  -H "Content-Type: application/json" \
  -d '{"vid": '$UAV_ID', "hard": false, "position": [0, 0, 5]}' | jq .

sleep 2

# 3. 检查是否就绪
echo "=== 等待PX4就绪 ==="
for i in $(seq 1 30); do
  ready=$(curl -s $SIM_URL/uav/$UAV_ID/px4/ready | jq -r '.ready')
  if [ "$ready" = "true" ]; then
    echo "PX4 ready!"
    break
  fi
  echo "Waiting... ($i/30)"
  sleep 1
done

# 4. 执行轨迹
echo "=== 执行轨迹 ==="
curl -s -X POST $CTRL_URL/command \
  -H "Content-Type: application/json" \
  -d '{
    "cmd": "execute_mission",
    "waypoints": [
      {"x": 0, "y": 0, "z": 5},
      {"x": 2, "y": 0, "z": 5},
      {"x": 2, "y": 2, "z": 5},
      {"x": 0, "y": 2, "z": 5},
      {"x": 0, "y": 0, "z": 5}
    ],
    "timeout": 120
  }' | jq .

# 5. 降落
echo "=== 降落 ==="
curl -s -X POST $CTRL_URL/command \
  -H "Content-Type: application/json" \
  -d '{"cmd": "land"}' | jq .

echo "=== 完成 ==="
```

#### 实时状态监控脚本
```bash
#!/bin/bash
# 实时监控所有UAV状态

while true; do
  clear
  echo "========== UAV Status Monitor =========="
  echo "Time: $(date '+%H:%M:%S')"
  echo ""
  printf "%-6s %-8s %-8s %-8s %-30s\n" "UAV" "Ready" "Armed" "Mode" "Position"
  echo "--------------------------------------------------------------"

  for i in $(seq 0 7); do
    # 获取状态
    status=$(curl -s --max-time 1 http://127.0.0.1:$((5009+i))/command \
      -H "Content-Type: application/json" -d '{"cmd": "get_status"}' 2>/dev/null)
    px4=$(curl -s --max-time 1 http://127.0.0.1:8081/uav/$i/px4/ready 2>/dev/null)

    if [ -n "$status" ]; then
      ready=$(echo $px4 | jq -r '.ready // "N/A"')
      armed=$(echo $status | jq -r '.status.armed // "N/A"')
      mode=$(echo $status | jq -r '.status.mode // "N/A"')
      pos=$(curl -s --max-time 1 http://127.0.0.1:8081/uav/$i/pose 2>/dev/null | \
        jq -r '.position | "(\(.[0]|round), \(.[1]|round), \(.[2]|round))"' 2>/dev/null || echo "N/A")
      printf "%-6s %-8s %-8s %-8s %-30s\n" "UAV$i" "$ready" "$armed" "$mode" "$pos"
    else
      printf "%-6s %-8s\n" "UAV$i" "OFFLINE"
    fi
  done

  sleep 2
done
```

## 常见问题排查

### 1. 控制器无响应
```bash
# 检查端口占用
ss -tlnp | grep 5009

# 重启控制器（杀死后会自动重启）
pkill -f "rospy_isaacsim"

# 检查日志
journalctl -f | grep -i error
```

### 2. PX4不就绪
```bash
# 检查PX4进程
ps aux | grep px4

# 检查MAVLink连接
curl -s http://127.0.0.1:8081/uav/0/px4/ready | jq .

# 检查MAVROS状态
ros2 topic echo /uav0/mavros/state --once
```

### 3. 图像获取失败
```bash
# 检查仿真服务
curl -s http://127.0.0.1:8081/uav/0/image | jq 'del(.data)'

# 检查图像服务延迟
time curl -s http://127.0.0.1:8081/uav/0/image > /dev/null
```

### 4. 坐标系问题
```bash
# 检查当前位姿
curl -s http://127.0.0.1:8081/uav/0/pose | jq '.position'

# 检查命令是否正确转换
# 输入: ENU (x=East, y=North, z=Up)
# PX4: NED (x=North, y=East, z=Down)
```

### 5. 多机同步问题
```bash
# 检查所有UAV状态
for i in $(seq 0 7); do
  echo "=== UAV $i ==="
  curl -s http://127.0.0.1:8081/uav/$i/px4/ready | jq -c .
  curl -s http://127.0.0.1:$((5009+i))/health | jq -c .
done

# 同步重置所有UAV
for i in $(seq 0 7); do
  curl -s -X POST http://127.0.0.1:$((5009+i))/reset \
    -H "Content-Type: application/json" \
    -d '{"hard": true}' &
done
wait
echo "All reset complete"
```
